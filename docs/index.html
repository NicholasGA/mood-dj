为什么不直接用 QQ音乐

它是工具，Mood DJ 是个 DJ

QQ音乐给你歌，算法静默运转。Mood DJ 像一个懂你的电台主持人——会聊、会记得你、会讲故事。

🎧 普通播放器

  • 选歌单 / 搜歌，自己点
  • 固定的「开心 / 伤感」标签
  • 推荐是静默的算法
  • 歌就是歌，没人陪你聊

✨ Mood DJ

  • 一句自然语言心情 → 现编整台电台
  • 人格化 DJ 串场，会接话、有性格
  • 记得你的口味，点名你常听的歌
  • 每首歌一句基于歌词的故事

🌈

桌面灯带模式

主窗收进托盘，屏幕底边留一条随音乐律动的光带；唱到歌词时，胶囊像液滴从光里浮出，间奏沉回。鼠标穿透不挡操作。

🎙️

人格化 DJ 串场

有名字、有调性、有口头禅的固定 DJ，开场、串场、接话都出自同一个「人」。

💚

会记得你

你喜欢的歌成为 DJ 的记忆——挑歌偏向你，串场里点名你的口味，像老朋友。

📖

每首歌一句故事

结合歌词，点出这首歌的情绪、主题或创作背景，听歌也听懂歌。

💬

对话点歌 / 调味

边听边说「来点没听过的」「再安静一点」「想听 chilichill」，AI 听懂并现调，无限续播不重复。

⚡

零配置开箱即用

装好登一下 QQ 就能用，AI 已内置，不用申请任何 API Key。想要专属额度也能填自己的。

开始用

下载，登 QQ，开台
